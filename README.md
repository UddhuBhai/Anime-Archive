# 🎬 Anime Archive

A unique **anime-inspired blogging platform** built using **Node.js**, **Express**, **EJS**, and **CSS**. Instead of traditional blog posts, every entry is treated as an **episode**, allowing you to turn your personal journey into an anime series complete with arcs, episode numbers, synopses, and story chapters.

## 📖 About

This project reimagines a standard CRUD blog as an anime streaming platform. Every post becomes an episode with its own title, arc, synopsis, and full story. Users can create new episodes, edit existing ones, delete them, and browse their entire journey through a clean, modern interface.

## 🚀 Features

* 🎬 Anime-themed blogging experience
* 📝 Create new episodes
* ✏️ Edit existing episodes
* 🗑️ Delete episodes
* 📚 Read full episode pages
* 🔢 Automatic episode numbering
* 🎭 Organize stories into arcs
* 📱 Responsive and modern interface
